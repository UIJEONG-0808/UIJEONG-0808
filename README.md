**주요 내용**
- Python Playwright를 활용한 리뷰 데이터 수집
- 리뷰 및 한줄평 텍스트 전처리
- 별점과 텍스트 감성 비교
- 장문 리뷰와 단문 리뷰의 감성 차이 분석

**주요 결과**
- 높은 별점에서도 부정적인 표현이 함께 나타나는 사례 확인
- 별점만으로는 독자의 실제 반응을 충분히 설명하기 어렵다는 점 발견
- 장문 리뷰가 단문 리뷰보다 풍부한 감성 정보를 포함하는 경향 확인

`Python` `Playwright` `Pandas` `Text Analysis`

## What I Have Learned

프로젝트를 진행하며 주어진 데이터를 분석하는 것뿐만 아니라,

**데이터 수집 → 전처리 → 분석 기준 설정 → 분석 → 결과 해석**

까지의 전체 과정을 직접 경험했습니다.

앞으로도 실제 데이터를 기반으로 문제를 정의하고,  
분석 결과를 의미 있는 정보로 연결할 수 있는 데이터 분석가로 성장하고자 합니다.
